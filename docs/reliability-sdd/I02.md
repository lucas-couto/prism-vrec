## Defect and reproduction

F03 second half, re-validated: `_promote_trial_best` returned silently (warning only) when the
trial-local file was missing, and `_evaluate_cell` (a) loaded `_best.pt` with a bare
`torch.load` — a truncated file surfaced as `_pickle.UnpicklingError` from deep inside torch,
(b) guessed hyperparameters for a flat state_dict. Combined with I01, an all-zero cell had no
file at all and `find_best_models` simply did not list it (cell vanished; confirmed by the I01
reproduction: `best.pt exists = False`).

## Implementation

Files: `src/steps/evaluate.py` (one hunk in `_evaluate_cell` + import; `torch` import dropped
as unused), `src/utils/checkpoint.py` (`load_best_checkpoint`: legacy flat state_dict
identified explicitly; `pickle.UnpicklingError` mapped to `BestCheckpointError`),
`src/utils/training.py` (promotion validation — landed in the I01 commit).

Promotion requires: file exists, deserialises, carries `model_state/hyperparams/best_metric/
n_users/n_items/selection_fingerprint`, finite metric, metric equal to the run's observed
best, fingerprint equal to the run's. Evaluation requires the same loadable payload; the
error propagates through `run()` so no done-marker is written for the cell.

Scientific invariants: the final `Evaluator` construction, masks, K values and tie policy are
untouched; the test asserts `protocol == full_ranking` on the produced rows.
