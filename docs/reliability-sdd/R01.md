## Defect and reproduction

F09 re-validated on the current checkout (`src/battery/execute.py`): only `fixed` had a distinct route; every other strategy sent a `search` cell to `_optimize_one_cell` (Optuna) and a `replay` cell to `create_study(...).best_params`, i.e. the RAW suggestion (`{total_dim, learning_rate}`) went straight to `train_replay`.

Evidence before the patch (scratchpad `repro_r01_r03_before.py`, prism-vrec-shell container, CUDA disabled):

- `hp_search.strategy: grid`, search cell, spies on both entry points: `_optimize_one_cell calls=1 train_replay calls=0` — grid called Optuna.
- `tests/test_battery_strategies_integration.py` on the unpatched executor: `grid` and `optuna` replay cells failed with `KeyError: 'latent_dim'` (raw `best_params` trained without expansion); `fixed` failed only on the new additive `strategy` key.
- Replay under a shared default checkpoint root: `_train_one_optuna_trial` used `CheckpointManager()` regardless of `paths.checkpoints`, so a seed-suffixed config still wrote its resume envelope to `checkpoints/`.

- Final evaluation (`_evaluate_one_cell`) is unchanged: it reads `_best.pt` from the seed-isolated results root, so the replay seed's own selected weights are evaluated.
