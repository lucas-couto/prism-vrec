## Implementation

Files: `src/utils/training.py`, `src/utils/checkpoint.py` (both landed in the I01 commit;
this task adds the interruption evidence). At every completed epoch boundary the envelope
stores current model, optimizer, RNG states, completed epoch, `epochs_without_improvement`,
scaler state (empty dict when disabled), `has_valid_observation`, `best_metric`, `best_epoch`
and `best_ref = {path, digest}` of the trial-local best, which is committed BEFORE the envelope.
Sampler position needs no cursor: `BPRBatchSampler.epoch(e)` is seeded by `(job_seed, e)`, so
the restored epoch index fully determines the next draw (documented in code).
`_restore_training_state` validates version, required keys, identity, best-ref existence +
digest + path (must be this trial's own file) before touching the model; loads model,
optimizer, scaler (when enabled) and RNG; restores the early-stop counter and best state.
Identity = digest of run_id, dataset, model name + class, embedding, hyperparams, n_users,
n_items, base seed, job seed, selection fingerprint, selection budget (epochs, batch_size,
patience, eval cadence) and the AMP regime.

Scientific invariants: loss, optimizer, sampler sequence, evaluator, cadence untouched.
