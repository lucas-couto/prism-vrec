## Defect and reproduction

F01 residual: before any OOM guard, `_per_user_frame` allocated `arange(n_items)` on the device and `_evaluate_batched` built every test user's train-index tensor on the device (`_ensure_train_idx_cache`); the item-block path passed a device slice of that vector. The CPU score vector and `np.lexsort` buffers had no budget. Reproduced by `tests/test_ranking_golden_fixture.py` (collection error on the pre-task tree: `HostMemoryBudgetError` / `host_ranking_bytes` absent, `_train_idx_host` / `_catalogue_ids_gpu` absent, no `device=` keyword); on the new tree all 15 tests pass.

## Implementation

Files: `src/evaluation/protocol.py`, `src/utils/memory.py` (helper only).

- Catalogue ids are host-resident (`torch.arange(n_items)` on CPU). The batched path transfers the full id vector once **inside** the OOM-guarded `_rank_user_chunk` (`_catalogue_ids_on`); the item-block path transfers only `all_items[start:stop]` per block inside its guarded call.
- Train masks: `_ensure_train_idx_host` keeps per-user `np.int64` arrays on the host; `_chunk_train_mask` assembles the `(row, col)` pairs of the current chunk only, transferred once per chunk and applied with one advanced-index assignment — identical to the previous per-user `index_fill_` (`-inf` on the same cells). `_train_idx_gpu` / `_ensure_train_idx_cache` are gone (no external users).
- **CPU score vector / sort budget — recorded design choice: design A** (reference full-vector ranking with a checked host budget). `host_ranking_bytes(n_items) = 40 B/item` (fp32 scores + negated copy + int64 lexsort output + int64 workspace + resident int64 tie key + boolean masks) is checked in `_admit_host_ranking` when the item-block path is entered: an explicit `host_budget_bytes` is enforced; `None` probes `available_host_bytes()` (min of cgroup headroom and `MemAvailable`); an unanswerable probe logs a warning and proceeds because no smaller exact alternative exists. Failure raises `HostMemoryBudgetError` with phase, `n_items`, bytes/item and budget — no records, no success marker. Streaming top-K was NOT introduced (its equivalence proof for the tie diagnostics would have required a second pass).
- Unchanged: candidate set (every item incl. cold, validation target as ordinary candidate), masks, seeded tie permutation, NaN guard, retry-on-failed-offset-only logic (M00), throughput accounting after success.

Scientific invariants: none touched (golden records identical under every layout).
