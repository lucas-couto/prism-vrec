## Implementation

Files: `src/data/feature_source.py` (new), `src/fusions/online.py` (loader only; non-learned normalisation semantics untouched — that is S02).

- `FeatureSource` runtime-checkable Protocol: `shape`, `dtype`, `read_rows(item_ids) -> np.ndarray`, `close()`.
- `NpyFeatureSource`: `.npy` header read at construction (shape/dtype, missing-file and 1-D/Fortran errors); read-only memmap opened on the first `read_rows` in the reading process, owner pid recorded, dropped from pickle state (`spawn` children reopen), released by `close()` (reopens on next read). `read_rows` validates 1-D integer ids in `[0, n)` (negative / too large -> `IndexError`, non-integer -> `TypeError`, 2-D -> `ValueError`), preserves caller order for repeated/unordered ids, returns a contiguous host-owned copy, keeps the on-disk dtype (fp16 component artifacts stay fp16), and an empty request keeps `(0, *trailing)` and dtype.
- `ConcatFeatureSource`: ordered native sources of differing widths, concatenated along axis 1 **per gathered row**; carries `source_dims`, `strategy`, `aligned_dim`, `normalize`, `fusion_kwargs` (same attribute names as `RaggedSources`, so the recommender builds its `LearnedAlignmentFusion` identically).
- `StackedFeatureSource`: ordered equal-shape sources stacked along a new axis 1 per gathered row (the non-learned sidecar). Rows are returned exactly as stored — the same (un-normalised) values the eager `np.stack` branch returns today; S02's fix, if it changes the eager branch, must be mirrored here (integrator note).
- `ArrayFeatureSource`: in-memory array behind the same interface (dense reference for tests).
- `source_bytes()`: `N * prod(trailing) * itemsize` for the memory ledger (a sidecar's JSON size is not its payload).
- `load_embedding(path, *, lazy=False)`: `lazy=True` dispatches to `_load_embedding_lazy`, which mirrors the eager branches one to one (`.meta.json` validation, non-empty component list, missing component -> `FileNotFoundError`, equal-shape check for the stacked sidecar, single-component warning). Shared parsing extracted to `_read_sidecar` (used by the lazy path only; the eager body is unchanged apart from the dispatch line).

Choice documented: opt-in keyword (not internal dispatch) so that every existing caller (`src/steps/train.py`, `src/utils/parallel.py`, `src/steps/evaluate.py`, `src/folds/runner.py`) keeps the dense array until the admission layer (M05) decides to pass `lazy=True`.

Scientific invariants: none touched (row identity is the file's row order; no filtering, no fabricated rows).
