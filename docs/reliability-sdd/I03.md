## Defect and reproduction

F07 re-validated on the current `FineTuner.train`: the envelope carried `best_acc` but not the
weights that produced it. Pre-patch reproduction (scratchpad `repro_i03.py`: toy backbone,
scripted `_validate`, exception injected inside the save path right after the epoch-two

`resumed best_val_acc=0.9, continuous best_val_acc=0.9, returned weights equal continuous
best = False` — the resumed run reported the epoch-one accuracy while returning epoch-four
weights. Confirmed behaviour.

## Implementation

Files: `src/finetuning/trainer.py`, `src/finetuning/checkpoint.py`.

- Historical best weights (CPU clones, as before) are committed to a sibling file
  `<ckpt>.best.pt` on every improvement, bound to the run identity and SHA-256 digested,
  BEFORE the envelope that references them (`best_ref = {path, digest}`). No extra GPU copy.
- Envelope v2 keeps every legacy field (model/optimizer/scheduler/scaler/RNG/epoch/
  `epochs_no_improve`) and adds identity + best reference; `best_acc` renamed to the
  canonical `best_metric` (the envelope has no reader outside the trainer).
- `_load_resume` validates envelope version, required keys, identity and the referenced best
  file (existence + digest + identity inside the file) BEFORE mutating the model; loads the
  best into memory only — never into the live model (trajectory unchanged); RNG states are now
  required (v2 always writes them).
- Identity = digest of extractor name, `n_classes`, `in_features`, unfreeze prefixes, the four
  optimisation hyperparameters (`epochs_max` also fixes the cosine schedule) and the AMP regime.
- Selection rule aligned with Q06: the first observation is the best even at 0.0 (previously an
  all-zero validation never set `best_state` and the LAST weights were returned; patience now
  resets at the first observation, so an all-zero run stops one epoch later than before).
- Cleanup on normal completion removes the envelope and the best sibling.

Scientific invariants: loss, optimizer, scheduler, augmentation/shuffle RNG restore, BN policy
untouched. Fine-tuning selection cadence (per epoch) unchanged.
