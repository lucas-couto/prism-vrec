## Implementation

Files: `src/utils/training.py`, `src/steps/train.py`, `src/utils/parallel.py`, `src/steps/evaluate.py`.

- `resolve_training_identity(...)` builds the C02 payload of a training run: data identity from `identity_context["data"]` (or explicit `unresolved`), model name + `implementation_digest`, effective hyperparameters, selection budget (epochs, batch size, patience, cadence, metric, sample size/seed), seed, selection protocol (full-ranking, k=[10], tie-break seed, fingerprint schema), condition, fold. `_training_resume_identity(identity, ...)` digests it together with a resume binding (run id, model class, n_users/n_items, job seed, fingerprint, AMP regime). `train_single_run` writes the identity into the trial-local best and the promoted `_best.pt`; `_save_best_model` treats a differing `selection_scope_digest` (identity minus hyperparameters) exactly like a fingerprint mismatch: not comparable, overwritten with a warning.
- Grid: the worker computes the same identity digest (same inputs, same helper) and records it in the grid-progress entry; `build_job_list` reuses an entry only when its digest equals the digest of the job it would submit. Legacy entries without a digest are counted and warned about, never reused. `identity_context_for` supplies the context to Optuna trials, replays and fixed cells.
- Evaluate: `evaluation_identity` binds dataset + train/val/test split digests, feature content, implementation, protocol (candidates, k, n_negatives, tie-break seed, `EVAL_PROTOCOL_VERSION`), seed, condition and the streamed digest of the selected `_best.pt`. The done table stores `checkpoint_digest` + `identity_digest`; a cell is skipped only when both match, otherwise it is re-evaluated with a warning naming the stale/legacy completion. `_record_done` now upserts one row per triple atomically (no duplicate rows on re-evaluation). The per-user artifact's `config_hash` carries the evaluation identity digest.
- Global cleanup removed from `train.run`; `CheckpointManager.clear_all_training_checkpoints` remains defined (contract) but has no caller.

Scientific invariants: none touched.
