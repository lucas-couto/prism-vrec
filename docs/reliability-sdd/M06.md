## Defect and reproduction

SPEC re-validated: `validate_matrix` did `np.load(path)` (whole catalogue resident) followed by `np.isfinite(matrix).all(axis=1)` (a full `(N, D)` boolean temporary) and `np.linalg.norm(matrix, axis=1)` (a full norm vector); for a 166k × 2816 fused matrix that is 1.9 GB resident plus a 470 MB mask. `detect_max_workers(..., per_worker_bytes=0)` sized the GPU pool from VRAM alone (`plan_pool_workers(0, ...)` returns the hard cap), i.e. against unlimited host memory, and `TrainingOrchestrator` honoured any pinned worker count verbatim. Pre-patch evidence: the new test file fails at collection on the pre-patch tree (`BLOCK_ROWS`, `UNKNOWN_WORKER_FOOTPRINT_BYTES` absent); `TestBoundedHostTemporaries` is the measurable half — on the old code the traced peak equals the full mask + norm vector.

## Implementation

Files: `src/steps/validate_features.py`, `src/utils/parallel.py` (+ the orchestrator enforcement from M05).

- `validate_matrix` reduces per block of `block_rows` (default 65 536): `_NormReducer.add(block, offset)` computes the block's finiteness mask and norms, counts offending rows, quotes at most ten with their *global* index, and accumulates count / sum / sum of squares / min / max in float64. Stats are identical to the whole-array computation (population std as `np.std`); shape/dtype checks are unchanged and run before any block is touched. `validate_backbone_feature` and `validate_fused_feature` open the file with `mmap_mode="r"` so a validation never materialises the catalogue.
- Pools: an unknown footprint (`per_worker_bytes <= 0`) is charged `UNKNOWN_WORKER_FOOTPRINT_BYTES` (2 GiB — interpreter + torch stack + CUDA context + one modest dataset) on both the CPU and the CUDA branch of `detect_max_workers`; the VRAM heuristic remains the other cap. `TrainingOrchestrator(admission=plan)` (M05 commit) clamps a pinned count above the admitted one with a warning and raises `AdmissionError` when nothing is admitted, so no pool starts against a budget that admits none.

Scientific invariants: none touched (validation verdicts are identical; block size is an execution detail — tested).
